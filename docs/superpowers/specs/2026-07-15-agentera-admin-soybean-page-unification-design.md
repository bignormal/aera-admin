# AgentEra Admin Soybean 全页面统一设计规格

## 1. 背景

AgentEra Admin 已经完成平台总览、统一导航和官方智能体列表的主要 Soybean 风格改造，但部分 Payload 原生页面仍保留默认视觉，导致管理员在列表、创建、编辑、媒体、账号和登录页面之间切换时出现明显风格断层。

本规格是以下既有设计的补充和收口，不替换其架构与产品边界：

- `docs/superpowers/specs/2026-07-15-agentera-admin-soybean-ui-design.md`
- `docs/superpowers/specs/2026-07-15-agentera-platform-admin-v1-design.md`

## 2. 目标

在不替换 Payload CMS、不改变数据库模型、权限、API、草稿、版本和发布流程的前提下，把 AgentEra 平台运营后台的全部真实管理页面统一为已确认的浅色 Soybean 风格。

完成后，超级管理员在平台页面与 Payload 真实业务页面之间切换时，应感受到同一套导航、排版、面板、表格、表单、按钮和状态系统，而不是两个拼接的网站。

## 3. 已确认决策

### 3.1 技术方案

采用“Payload 原生业务组件 + 共享 Soybean 样式层 + 少量页面包装组件”。

- Payload 继续负责认证、授权、路由、查询、筛选、排序、分页、批量选择、表单、上传、草稿、版本和发布。
- 共享设计令牌和 SCSS 覆盖负责通用视觉。
- 少量包装组件只负责标题区、页面分区和必要的信息层级，不复制 Payload 的数据或权限逻辑。
- 不建立独立 Soybean Vue/React SPA。

### 3.2 数据与功能

- 官方智能体列表保留已有四张真实统计卡。
- 智能体分类、技能目录、媒体资源和管理员列表不增加统计卡，使用紧凑的标题、工具栏和内容面板。
- 不增加假统计数据。
- 不改变任何真实写操作的业务语义。

### 3.3 主题范围

- 本轮仅实现浅色主题。
- 顶部主题切换按钮继续作为不可操作占位。
- 设计令牌保留后续扩展深色主题的结构，但本轮不提供深色配色或切换逻辑。

## 4. 页面范围

### 4.1 独立认证页面

- `/admin/login`
- Payload 认证流程触发的忘记密码、重置密码或首次登录状态（如果当前配置可访问）

### 4.2 完整后台外壳页面

- `/admin/account`
- `/admin/collections/agent-templates`
- `/admin/collections/expert-categories`
- `/admin/collections/skill-catalog`
- `/admin/collections/media`
- `/admin/collections/admins`

### 4.3 创建、编辑与详情页面

上述真实集合的：

- 创建页；
- 编辑页；
- Payload 自动生成的版本、草稿和发布相关页面或状态；
- 媒体上传、预览和编辑状态；
- 账号资料与管理员编辑状态。

### 4.4 通用浮层与反馈

- 下拉菜单；
- 关系选择器；
- 筛选器；
- 列设置；
- 日期选择器；
- 弹窗与确认框；
- 抽屉；
- 通知与错误提示；
- 加载、空数据、禁用和权限不足状态。

## 5. 页面结构

### 5.1 后台外壳

- 延续现有 AgentEra 左侧导航、顶部栏、面包屑和账号入口。
- 桌面端页面内容区使用统一水平留白。
- 页面标题、说明和主操作位于内容区顶部，不能被顶部栏遮挡或贴边。
- Payload 原生页面不得重新渲染第二套导航或标题栏。

### 5.2 标准列表页

除官方智能体外，真实集合列表采用统一紧凑结构：

1. 页面标题与说明；
2. 右侧主操作按钮；
3. 搜索、筛选和列设置工具栏；
4. 表格或媒体网格面板；
5. 批量选择与分页区域。

官方智能体列表在标题区与工具栏之间保留现有四张真实统计卡。其他集合不得复制这些卡片。

### 5.3 创建与编辑页

- 保留 Payload 的字段渲染、校验和提交行为。
- 主表单区和右侧文档状态区使用同一面板体系。
- 字段分组、标签、说明、输入框、文本域、关系选择器、日期选择器和上传区需要形成一致的垂直节奏。
- 保存、发布、取消和删除按钮保持 Payload 的真实权限与状态判断。
- 只调整视觉层级和布局，不隐藏必要状态，不把危险操作伪装成普通操作。

### 5.4 登录页

- 使用浅色背景和居中的白色品牌卡片。
- 展示 AgentEra 标志、系统名称、登录标题、邮箱、密码、提交按钮及 Payload 必要反馈。
- 不增加营销介绍、指标卡或无关入口。
- 错误、禁用、加载和焦点状态必须清晰可见。

### 5.5 账号页

- 继续显示在完整后台外壳中。
- 账号资料、密码和会话相关内容使用标准表单面板。
- 不改变 Payload 的账号更新、退出或安全行为。

## 6. 视觉系统

### 6.1 颜色

- 页面背景：`#f5f7fb`。
- 内容面板：`#ffffff`。
- 主色：`#646ced`。
- 主色 hover：`#555edc`。
- 主色浅背景：`#f0f1ff`。
- 主文字：`#2f3342`。
- 次要文字：`#9499a9`。
- 边框：`#eef0f5`。
- 成功、警告和危险状态继续使用现有语义色，不用主色替代。

### 6.2 圆角与阴影

- 输入框、按钮和小型控件：`8px`。
- 页面面板、弹窗和抽屉：`10px`。
- 登录卡片可使用 `14px`，作为独立认证页面的唯一较大圆角。
- 页面面板阴影：`0 3px 12px rgb(36 50 82 / 6%)`。
- 弹层使用更明显但克制的阴影，不使用发光或高饱和渐变。

### 6.3 排版

- 字体栈沿用 `Inter`, `SF Pro Display`, `PingFang SC`, `Microsoft YaHei`, sans-serif。
- 页面主标题约 `22px`、`700` 字重。
- 页面说明约 `12px`，使用次要文字色。
- 工具栏、按钮、字段标签、表头和分页使用明确的 `11–12px` 控件字号，不依赖浏览器默认字号。
- 正文和表格文本保持可读，不用过浅灰色承载关键信息。

### 6.4 表格与媒体网格

- 表头使用极浅灰背景和清晰列分隔。
- 标准数据行高度约 `58–66px`。
- hover 使用很浅的蓝紫背景。
- 选择框、排序箭头和操作菜单视觉居中。
- 状态使用小型语义标签，不改变原状态值。
- 分页与内容表格属于同一白色面板体系。
- 媒体卡片使用同一边框、圆角、标题和元信息规范；预览图保持原比例，不拉伸。

### 6.5 表单控件

- 输入框、文本域、关系选择器、日期选择器和上传控件共享背景、边框、圆角、字体和焦点环。
- 默认背景使用 `#fbfcfe`，聚焦时切换为白色。
- 聚焦边框使用半透明主色，并显示克制的三像素焦点环。
- 错误状态使用危险色边框和可读错误文字，不被主色覆盖。
- 禁用和只读状态应能被识别，同时保持文字可读。

### 6.6 浮层与反馈

- 下拉、关系菜单、筛选器、弹窗、抽屉和通知共享边框、`10px` 圆角和统一阴影。
- 菜单项 hover、选中和禁用状态保持一致。
- 确认和危险操作继续使用语义按钮，不统一成蓝紫主按钮。

## 7. 响应式规则

### 7.1 桌面端

- `≥1180px` 显示完整侧栏。
- 点击左侧导航后侧栏保持展开。
- 标题、工具栏、表格和表单不能横向溢出视口。

### 7.2 中等宽度

- `769–1179px` 使用图标侧栏。
- 表格在自己的内容面板内横向滚动，不压缩至不可读。
- 主操作按钮保持可见。

### 7.3 手机端

- `≤768px` 使用抽屉侧栏。
- 进入页面时默认关闭，点击导航后自动关闭。
- 标题区和主操作允许上下排列。
- 表单主区和状态侧栏改为单列。
- 页面根节点不得产生意外横向滚动。

## 8. 行为与边界

- 搜索、排序、筛选、列设置、分页和批量选择继续调用 Payload 原生行为。
- 关系选择器、媒体上传、校验、保存、草稿、发布、删除和版本行为不得被视觉包装替换。
- 服务端访问规则继续作为最终授权边界。
- 自定义包装组件异常时，核心 Payload 路由仍应可通过直接 URL 访问。
- 本轮不新增数据库集合、字段、API 或真实业务写入。

## 9. 错误处理

- 加载失败显示非阻塞错误或 Payload 原生错误提示。
- 字段错误必须与对应字段保持视觉关联。
- 权限不足时保留 Payload 的拒绝结果，不显示无权限主操作。
- 上传失败、关系查询失败和提交失败不得只依赖控制台信息。
- 风格层不得隐藏错误、草稿、发布中、禁用或只读状态。

## 10. 测试与验收

### 10.1 自动化测试

Playwright 视觉行为断言至少覆盖：

- 登录品牌卡片；
- 标准集合标题区、工具栏和表格面板；
- 官方智能体统计卡仍存在；
- 分类、技能、媒体和管理员列表不出现统计卡；
- 创建和编辑页面的主表单、右侧状态区及输入控件；
- 关系选择器或下拉菜单；
- 桌面端导航保持展开；
- 手机端无横向溢出并保持抽屉行为。

现有集成测试继续证明 Payload 访问规则、统计映射和目录接口未被改变。

### 10.2 浏览器逐页验收

逐页检查：

- `/admin/login`；
- `/admin/account`；
- 五个真实集合列表；
- 五个真实集合的创建或编辑页；
- 媒体上传和预览；
- 至少一个关系选择器、筛选器、列设置、弹窗和分页状态；
- 桌面、当前浏览器宽度和一个手机宽度。

每个页面必须满足：页面身份正确、内容非空、无框架错误覆盖层、无相关控制台错误、主交互可用、无明显裁切或横向溢出。

## 11. 不在本轮范围

- 深色主题；
- 独立 Soybean SPA；
- 用户、租户、计费或 Runtime 的真实后台数据模型；
- 新权限系统或租户 RBAC；
- 更换 Payload 认证、表单或发布实现；
- 为非官方智能体集合添加统计卡；
- 对平台演示模块增加真实写操作。

## 12. 完成标准

- 全部真实管理页面使用同一套 AgentEra Soybean 视觉语言。
- 平台页面与 Payload 页面之间不存在明显的默认主题断层。
- Payload 的真实业务行为、权限和发布语义保持不变。
- 桌面、中等宽度和手机端均无阻塞性布局问题。
- lint、相关集成测试、端到端测试和逐页浏览器验收通过。
