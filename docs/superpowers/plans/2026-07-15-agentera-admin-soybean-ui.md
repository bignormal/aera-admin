# AgentEra Admin Soybean UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the approved Soybean-style AgentEra admin shell and official-agent list while preserving Payload authentication, permissions, collection behavior, and publishing workflows.

**Architecture:** Keep Payload CMS as the routing and behavior owner. Add focused Payload custom components for branding, navigation, the dashboard, list overview, and list cells; use one SCSS theme layer to restyle the remaining Payload controls without duplicating collection logic.

**Tech Stack:** Payload CMS 3.86, Next.js 16, React 19, TypeScript, SCSS, Vitest, Playwright, SQLite.

---

```ts
export type AgentCounts = { all: number; draft: number; published: number; recent: number }

export function toAgentStats(counts: AgentCounts) {
  return [
    { key: 'all', label: '全部智能体', value: counts.all },
    { key: 'published', label: '已发布', value: counts.published },
    { key: 'draft', label: '草稿', value: counts.draft },
    { key: 'recent', label: '本月新增', value: counts.recent },
  ] as const
}

export function agentInitial(name: string | null | undefined): string {
  return name?.trim().charAt(0).toUpperCase() || 'A'
}
```
