# Aera Admin

Aera 平台运营方使用的 Payload CMS 系统总后台。

当前前置版本提供：

- 中文管理员登录与超级管理员、内容发布员权限；
- 官方智能体、分类、技能元数据和头像管理；
- 草稿、发布、下架、历史版本及发布版本号；
- 六个可编辑的官方智能体初始草稿；
- 供 Aera 使用的已发布专家目录 API。

后台界面已基于 Payload 自定义组件改造成 Aera 的 Soybean 风格管理界面，包括：

- Aera 品牌侧栏和管理员角色摘要；
- 真实数据驱动的后台首页概览；
- 官方智能体状态概览、头像名称单元格和业务化列表列；
- 统一的按钮、表单、表格、状态色和响应式布局；
- 保留 Payload 原有的登录、权限、草稿、版本、筛选、分页和发布行为。

## 平台总后台 V1

`/admin` 是 Aera 平台运营方使用的系统总后台。官方智能体、智能体分类、技能目录、媒体资源和管理员继续使用 Payload 真实集合，并遵循现有访问规则。

用户、租户、账号审核、模型、Runtime、任务、套餐、订单、公告、审计日志和系统设置页面是确定性的只读演示页面。所有演示指标均在界面中显示“演示数据”，不会写入 SQLite，也不会调用真实外部服务；后续接入真实数据适配器时保持现有路由和页面结构。

普通用户注册、多租户真实数据、统计遥测、批量发布、邮件流程、真实计费和云部署暂未开放，保留为后续版本能力。

## 本地开发

1. 复制 `.env.example` 为 `.env`，并替换 `PAYLOAD_SECRET`。
2. 运行 `pnpm install`。
3. 运行 `pnpm dev --port 3100`，打开 <http://localhost:3100/admin>。
4. 首次进入时创建第一个超级管理员。
5. 运行 `pnpm seed`，创建六个可编辑的官方智能体草稿。

## 官方专家目录

公开只读接口：

```text
GET /api/catalog/v1/experts
```

草稿和已下架记录不会出现在接口中。接口不会输出 CMS 内部 ID、管理员信息或原始编辑记录。
